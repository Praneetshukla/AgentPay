## 1. Core Principles & Strict Guardrails

1. **Real-Event Driven Animations (No Synthetic Delays):**
   - Animation states must strictly match incoming `result.trace_steps` and `recovery_history` from the server.
   - Zero fabricated timers or fake thinking loops.
2. **Authentic Razorpay Test-Mode Handoff (No Fake Gateway Skins):**
   - Use the real Razorpay integration.

   - Judge showcase buttons simply load dynamic natural-language prompts and dynamically read current policy limits. They execute through the exact same `/agent/buy`, `/agent/cart/quote`, `/agent/policy/evaluate`, and `/agent/confirm` pipeline as human input.
5. **Technically Defensible Terminology:**
   - Strictly avoid: "unbreakable", "on-chain", "hack-proof".
   - Strictly use: "server-authoritative", "cryptographically tamper-evident", "HMAC-SHA256 signed", "human authorization required", "SHA-256 Merkle hash chain".

## 2. Detailed Technical Plan: The 5 Upgrades

### Upgrade 1: Interactive Node Evidence Inspector in `LangGraphVisualTracer.tsx`
- **What it does:**
  - Clicking any node (`Goal`, `Intent`, `Catalog`, `Rank`, `Optimizer`, `Quote`, `Policy Gate`, `Recovery`) opens an **Interactive Evidence Drawer**.
  - **Evidence Payloads Exposed:**
    - **Intent Node:** Extracted target categories, parsed budget limit, excluded categories.
    - **Catalog & Rank Node:** Candidates evaluated, composite scores ($0.35\text{ rel} + 0.25\text{ cat} + 0.25\text{ avail} + 0.15\text{ bud}$), in-stock flags.
    - **Quote Node:** Real `quote_id`, HMAC-SHA256 signature string, expiration timestamp, server-locked line items.
    - **Policy Gate Node:** Active policy ID & version, 10 individual check results (`check_name`, `passed`, `code`, `message`), decision (`ALLOW` / `REQUIRE_CONFIRMATION` / `BLOCK`).
    - **Recovery Branch (when active):** Strategy triggered (`REMOVE_LOW_RELEVANCE`, `REDUCE_QUANTITY`), before total, after total, affected SKUs, real reason.

---

### Upgrade 2: Dynamic Dual-Slider Authority Range in `DelegationContractView.tsx`
- **What it does:**
  - Upgrades budget & confirmation threshold into smooth, dynamic sliders with real-time computed authority zones:
    - **Autonomous Headroom Zone:** $0 \rightarrow \text{Threshold}$ (Green)
    - **Human Confirmation Gate:** $\text{Threshold} \rightarrow \text{Spending Ceiling}$ (Amber)
    - **Hard Block Zone:** $> \text{Spending Ceiling}$ (Red)
  - Dynamically saves to SQLite policy table (`PATCH /agent/policy/policy_demo`) before launching mission.

---

### Upgrade 3: Transparent Razorpay Test Execution Handoff in `TransactionGuardianModal.tsx`
- **What it does:**
  - When human clicks *"Authorize & Execute"*, displays the real backend order creation state:
    - Target: `Razorpay Test Environment`
    - Order ID: `order_mock_...` / `order_rzp_...` generated by `ExecutionService`
    - Transaction State: `PAYMENT_PENDING` $\rightarrow$ `PAID` via webhook capture
    - Currency: `INR`
    - Non-interactive status stream displaying the exact cryptographic authorization signature.

---

### Upgrade 4: Visual Cryptographic Merkle Block Chain in `MissionHistoryLedger.tsx`
- **What it does:**
  - Adds a toggle to switch between tabular view and **Visual Hash Chain View**:
    - Each block displays `Block #ID`, `Event Type`, `Timestamp`, and `event_hash`.
    - Visual connection lines show `previous_event_hash` pointers linking directly to the prior block.
    - Clicking a block inspects its raw canonicalized payload and live cryptographic integrity status.

---

### Upgrade 5: Dynamic Showcase Quick-Launcher in `AgentBuyerConsole.tsx`
- **What it does:**
  - Replaces hardcoded prompts with 4 dynamically generated showcase scenarios that read current policy:
    1. 🎯 **"Autonomous Purchase"** $\rightarrow$ Goal under confirmation threshold.
    2. 🛡️ **"Confirmation Gate"** $\rightarrow$ Goal between threshold and ceiling.
    3. 🔄 **"Autonomous Recovery"** $\rightarrow$ Goal triggering stockout or headroom adaptation.
    4. 🚫 **"Adversarial Prompt Guard"** $\rightarrow$ Prompt injection goal attempting to exceed ceiling.
  - All scenarios route through the exact same standard user flow with zero privileged execution bypasses.
